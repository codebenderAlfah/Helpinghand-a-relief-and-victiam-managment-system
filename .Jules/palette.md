## 2026-03-08 - Improving Form Accessibility and UX in Legacy PHP
**Learning:** Legacy PHP forms often lack basic HTML5 accessibility and UX features like label-input associations, specific input types, and autocomplete attributes. These small additions significantly improve the experience for screen readers and users with password managers.
**Action:** Always check for `id`/`for` pairs in labels, use semantic `type` attributes (e.g., `email`), and provide `autocomplete` hints on all login and registration forms.
