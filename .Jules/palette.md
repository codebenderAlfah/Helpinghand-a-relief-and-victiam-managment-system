## 2026-03-08 - [Legacy Form Accessibility & CSS Syntax]
**Learning:** Legacy PHP forms in this repository frequently omit the 'id' and 'for' attributes necessary for programmatic label-input association. Additionally, some CSS files contain invalid property combinations (e.g., 'border-radius: 5px solid gray;') that prevent correct rendering of input fields.
**Action:** When modifying legacy pages, always establish explicit label associations and audit CSS for invalid property shorthand to ensure both accessibility and visual consistency.
