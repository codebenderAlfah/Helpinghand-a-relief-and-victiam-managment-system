## 2026-03-10 - [Accessibility] Label-Input Associations and Semantic HTML
**Learning:** Legacy PHP forms often lack basic accessibility features like `for`/`id` associations, which are critical for screen readers. Additionally, missing HTML5 boilerplate (doctype, lang, charset) can lead to rendering and accessibility issues.
**Action:** Always verify form accessibility by checking for programmatic label associations and ensure all pages have standard HTML5 metadata and semantic input types (e.g., type="email").
